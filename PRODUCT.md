# 诗境 · 全唐诗文本图谱

An openly accessible Chinese Tang-poetry exploration website for a text-analysis assignment. Source: user-provided Quan Tang Shi corpus. Required: D3 v4/v5 bars, image categories, smooth linked updates. User approved classical ink-wash imagery with contemporary interactions and GitHub Pages publication.

Primary flow: move among three research views. In the imagery atlas, choose a category, compare occurrence/record counts, select a word, and read matching source poems. The poet-emotion view compares disclosed lexicon counts normalized per 10,000 Han characters. The poet-cluster view uses exact jieba segmentation, TF-IDF, dimensionality reduction, and K-means to explore diction similarity. Methods and limitations remain visible. No invented statistics or citations. No login required for visitors.

Scope: responsive static Vite website, GitHub repository and Pages. Controls include top-level view tabs, ranking, metric, CSV export, poem browsing and full-text reading, poet search, emotion evidence, cluster filtering, motion toggle, and methodology. Source IDs retain volume and record IDs, grouped poems are not split. Sentiment categories are lexicon-based expression signals, not inferred author psychology; cluster labels and 2D positions are exploratory, not literary schools or value judgments.

Imagery direction: each of the five imagery categories owns a distinct original ink-wash master scene. Term selection changes crop, atmosphere, pigment, weather, and focal depth without compromising chart or navigation contrast. Poet-emotion changes preserve object continuity: radar geometry, frequency bars, numbers, headings, and evidence morph in place instead of replacing the whole panel.
