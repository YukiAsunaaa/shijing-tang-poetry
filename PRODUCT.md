# 诗境 · 全唐诗意象图谱

An openly accessible Chinese Tang-poetry exploration website for a text-analysis assignment. Source: user-provided Quan Tang Shi corpus. Required: D3 v4/v5 bars, image categories, smooth linked updates. User approved classical ink-wash imagery with contemporary interactions and GitHub Pages publication.

Primary flow: choose category, compare occurrence/record counts, select a word, read matching source poems. Five categories: seasons, plants, landscape, sky, colors. Python preprocesses literal counts; limitations visible. No invented statistics or citations. No login required for visitors.

Scope: responsive static Vite website, GitHub repository and Pages. Sentiment analysis and poet clustering are explicitly outside first release. Controls include ranking, metric, CSV export, poem browsing and full-text reading, motion toggle, and methodology. Source IDs retain volume and record IDs, grouped poems are not split.
